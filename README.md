**User-Friendly Online Encyclopedia
**
This project is a user-friendly online encyclopedia designed to replicate the structure and functionality of Wikipedia. Built with Django and SQLite, the platform allows users to search for, read, and contribute to articles, all while offering a clean, easy-to-navigate interface.
Features

    Article Browsing: Users can search for articles or browse through various categories to access content.
    Content Creation & Editing: Registered users can create, edit, and update articles, contributing to the knowledge base.
    User Authentication: Secure user sign-up and login, allowing for personalized accounts and article contributions.
    Article History: Track the history of each article with the ability to view changes and revert to previous versions.
    Category System: Articles are organized into categories for easy browsing and navigation.
    Search Functionality: Powerful search feature to help users find articles by keywords or topics.
    Responsive Design: The interface is fully responsive, providing a seamless browsing experience across devices.

Technologies Used

    Django: A high-level Python web framework used for managing the back-end logic, database operations, and user interactions.
    SQLite: A self-contained database used to store user data, article content, and metadata.
    HTML/CSS/JavaScript: Front-end technologies to build a responsive, clean, and accessible user interface.
    Markdown: Used for formatting article content in a simple, readable way.
    REST API: Facilitates article creation, editing, and retrieval in a scalable manner.
